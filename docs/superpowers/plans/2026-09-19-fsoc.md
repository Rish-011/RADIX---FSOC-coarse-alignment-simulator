# FSOC implementation plan

**Goal:** Deliver the requested desktop simulation and evaluator-video application.

**Architecture:** Typed independent numerical modules, a shared perception pipeline,
and a PyQt6 main-thread UI with queued commands and bounded display delivery.

**Tech Stack:** Python 3.10+, NumPy, OpenCV, ONNX Runtime, PyQt6, pyqtgraph,
Pandas, ReportLab and PyInstaller.

**Spec:** `docs/design.md`; user's detailed architecture is the approved scope.

## Validation and implementation sequence

  disturbances, separated centroids, crossing identity, EKF coasting, all seven
  FSM states, PID convergence, video coordinate mapping, exports and shutdown.
- [x] Run `python -m pytest` to expose missing modules.
- [x] Implement `math3d_engine.py`, `disturbances.py`, `perception_ekf.py`,

- [x] Document measured results, assumptions, installation and model format.
