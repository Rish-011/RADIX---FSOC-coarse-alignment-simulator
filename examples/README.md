# Synthetic Benchmark-2 example

Drag `annotated_benchmark.mp4` into the dashboard. Its matching CSV is loaded
automatically. This generated 1280 x 720 video contains one moving 10 x 10 beacon,
180 frames at 30 FPS. It is a functional demonstration fixture, not evaluator data.
The CSV uses zero-based frames and pixel-center centroids in the original video.
